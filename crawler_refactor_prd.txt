===============================================
크롤러 모듈화 리팩토링 PRD (Product Requirements Document)
===============================================

프로젝트명: Real Estate Auction Crawler Modularization
버전: 1.0
작성일: 2025-01-16
목적: 현재 단일 파일 크롤러(crawler.py, 368줄)를 모듈화하여 유지보수성과 확장성 향상

===============================================
1. 프로젝트 개요
===============================================

1.1 현재 상황
- 단일 파일(crawler.py)에 모든 기능 집중
- 총 368줄의 코드
- 설정관리, 드라이버, 로그인, 검색, 스크래핑 로직이 혼재
- 테스트 및 유지보수 어려움

1.2 목표
- 기능별 모듈 분리를 통한 코드 구조 개선
- 단일 모듈 최대 80줄 이하로 제한
- 재사용 가능한 컴포넌트 설계
- 테스트 용이성 확보

===============================================
2. 기능 요구사항
===============================================

2.1 핵심 기능 유지
- 부동산 경매 사이트 로그인
- 저장된 검색조건('조건1번') 실행
- 전체 페이지 데이터 수집
- JSON 결과 저장
- 디버그 모드 (스크린샷, HTML 저장, 단계별 지연)

2.2 신규 요구사항
- 모듈별 독립 테스트 가능
- 설정 변경 시 해당 모듈만 수정
- 새로운 사이트 추가 시 확장 용이
- 로깅 시스템 개선

===============================================
3. 기술 요구사항
===============================================

3.1 모듈 구조
src/
├── core/
│   ├── config.py          (50줄) - 설정 관리
│   ├── driver.py          (60줄) - 웹드라이버 관리
│   └── debug.py           (40줄) - 디버그 및 로깅
├── automation/
│   ├── base.py            (80줄) - 기본 자동화 클래스
│   ├── login.py           (30줄) - 로그인 처리
│   ├── search.py          (60줄) - 검색 처리
│   └── navigation.py      (40줄) - 페이지 이동
├── scraping/
│   ├── parser.py          (50줄) - 데이터 파싱
│   └── collector.py       (60줄) - 페이지네이션 수집
├── utils/
│   ├── file_handler.py    (30줄) - 파일 저장/로딩
│   └── locators.py        (20줄) - 셀렉터 관리
└── main.py                (50줄) - 메인 실행

3.2 기술 스택
- Python 3.8+
- Selenium 4.6+
- 기존 의존성 유지

===============================================
4. 인터페이스 설계
===============================================

4.1 Configuration Interface
```python
class Config:
    @classmethod
    def load(cls, config_file: str) -> 'Config'
    def get(self, key: str, default=None)
    def get_locator(self, name: str) -> Tuple[By, str]
```

4.2 Driver Interface
```python
class WebDriver:
    def __init__(self, config: Config)
    def get_driver(self) -> webdriver.Chrome
    def quit(self)
```

4.3 Automation Interfaces
```python
class BaseAutomation:
    def __init__(self, driver: WebDriver, config: Config)
    def wait_for_element(self, locator: Tuple[By, str])
    def retry_on_failure(self, func, *args, **kwargs)

class LoginHandler(BaseAutomation):
    def login(self, credentials: Dict) -> bool

class SearchHandler(BaseAutomation):
    def execute_saved_search(self, search_name: str) -> bool
```

4.4 Scraping Interfaces
```python
class DataParser:
    def parse_auction_table(self, driver) -> List[Dict]

class DataCollector:
    def __init__(self, parser: DataParser, driver: WebDriver)
    def collect_all_pages(self, max_pages: Optional[int] = None) -> List[Dict]
```
